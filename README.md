# odoo-smtp-envvars

Configure SMTP settings from environment variables.

## Modules

| Module | Description |
|--------|-------------|
| mail_smtp_envvars | SMTP configuration via environment variables |

## Usage

Set environment variables:
- `SMTP_HOST`
- `SMTP_PORT`
- `SMTP_USER`
- `SMTP_PASSWORD`
- `SMTP_TLS` (True/False)
